# CadPilot AI

Phase 1 foundation for a tablet-native AI CAD, LiDAR, and AR platform. This phase contains the Flutter tablet shell, local-first authentication and projects, durable autosave, plus the NestJS/Prisma cloud foundation. CAD geometry and spatial features remain gated to later phases.

See `docs/architecture.md` and `docs/phase-1-verification.md`.
